# Demonstration checklist

Initialize an empty database, create a local administrator, and register a separate synthetic user. Enroll MFA and keep enrollment material private. Create a protected app whose account identifier matches the configured portal username. Save the one-time API client credentials locally and start the portal with those values.

Demonstrate successful login, wrong-code denial, replay denial, identity mismatch, and sanitized audit records. Never capture QR codes, seeds, recovery codes, passwords, secret URLs, or API credentials in screenshots. No screenshots are supplied because the original data is unsuitable for public reuse.
